# Інтерактивний навчальний сайт

**Тема 2. Заняття 1. Основи збору та зберігання даних для ІАЗ ОУВ**

## Запуск

1. Розпакуйте архів.
2. Відкрийте файл `index.html` у сучасному браузері.
3. Підключення до Інтернету не потрібне.

## Можливості

- повний навчальний матеріал;
- навігація за модулями та пошук;
- калькулятор якості даних;
- вправа ETL;
- радник з вибору сховища;
- ситуаційне завдання щодо дублікатів;
- тест із 12 запитань;
- збереження прогресу в Local Storage;
- світла/темна тема;
- адаптивна верстка та режим друку.
